## Описание

Проектът моделира онлайн платформата Goodreads – социална мрежа за книги и читатели.
Базата съхранява книги, автори, издателства и жанрове, както и потребители, които подреждат книги по рафтове
(*want-to-read*, *currently-reading*, *read* и собствени рафтове), пишат ревюта и оценки, добавят цитати,
следват други читатели и си поставят годишни цели за четене.

Проектът включва:
- концептуален модел (нотация на Чен), логически модел (Crow's Foot) и физически модел на Data Warehouse (UML) – папка `diagrams/`;
- база данни в Microsoft SQL Server с 13 таблици, 4 функции, 4 съхранени процедури, 4 тригера и тестови данни – папка `database/`;
- доклад в Power BI с 4 визуализации, 5 карти с показатели и филтър по държава – папка `powerbi/`.

## Инсталация и стартиране

### Изисквания
- Microsoft SQL Server 2019 или по-нов (Express или Developer)
- SQL Server Management Studio (SSMS)
- Power BI Desktop
- draw.io

### 1. База данни
Отворете SSMS, свържете се към сървъра и изпълнете скриптовете от папка `database/` **в този ред**:

1. `01_create_database.sql` – създава базата `Goodreads` и таблиците
2. `02_functions.sql` – функции
3. `03_triggers.sql` – тригери
4. `04_stored_procedures.sql` – съхранени процедури
5. `05_seed_data.sql` – тестови данни

> Скрипт 01 изтрива и създава базата наново, така че за начално състояние се пускат отново 01–05.

### 2. Power BI доклад
1. Отворете `powerbi/Goodreads_Report.pbix` с Power BI Desktop.
2. Ако сървърът не е `localhost`: **Transform data → Data source settings → Change Source** и въведете името на сървъра.
3. Натиснете **Home → Refresh**.

### 3. Диаграми
Файловете `.drawio` са в папка `diagrams/`.
